# 작은 노트

공식 create-next-app으로 생성한 JavaScript·App Router 메모 앱입니다.

```powershell
npm ci
npm run dev
```

홈에서 Counter를 조작하고 Link로 `/notes`에 이동합니다. 메모는 useState로 관리하여 새로고침하면 초기 값으로 돌아갑니다.
개발 서버를 종료한 뒤 `npm run build`, `npm run start`로 프로덕션 실행합니다.

전체 실행 방법, React와 Next.js의 관계, 컴포넌트 역할, DB 심화·검증 결과는 [저장소 README](../README.md)와 [검증 기록](../VERIFICATION.md)에 있습니다.
